Detection and Classification of Small-sized UAVs and Birds in Sparse LiDAR Point Cloud
Krisztián Balla, Anita Keszler, Sándor Gazdag, András L. Majdik
HUN-REN Institute for Computer Science and Control, Budapest, Hungary
Motivation and Problem Statement
  • Consumer drones pose safety and privacy risks for critical infrastructure
  • Existing RADAR and camera-based methods have limitations for 3D detection
  • Rosette scanning LiDAR provides sparse point clouds, making detection challenging
  • Key challenge: Distinguishing UAVs from birds and filtering false positives
  • Goal: Real-time detection and classification using only LiDAR data
Related Work
  • Prior work uses octomap-based static background subtraction
  • Camera and RADAR methods lack 3D spatial accuracy or require expensive hardware
  • Existing methods struggle to distinguish UAVs from birds in dynamic scenes
  • Our approach: LiDAR-only detection and classification up to 100 m
Proposed Solution Pipeline
  • Raw point cloud input from rosette scanning LiDAR
  • Semantic segmentation removes static and dynamic background
  • Foreground points clustered and preprocessed
  • Modified PointNet classifies objects as drone or bird

Semantic Segmentation Network
  • Spatial transformer (T-Net) aligns point clouds to a uniform space
  • Multi-head attention captures global context between points
  • Directly uses points as tokens, skipping voxelization
  • MLP assigns background or foreground class to each point

Preprocessing and Classification
  • Background points removed; foreground points clustered
  • Clusters with fewer than 3 points discarded as noise
  • Nearest Neighbour Search recovers missed foreground points
  • Voxel grid ensures uniform input for classification
  • Modified PointNet classifies clusters as drone, bird, or unknown
Component-wise Inference Speed
  • All pipeline components achieve real-time speeds
  • Mean processing time per frame: segmentation 4.29 ms, clustering 1.65 ms, preprocessing 4.11 ms, classification 6.44 ms
  • System operates at >10 FPS, suitable for real-time applications
