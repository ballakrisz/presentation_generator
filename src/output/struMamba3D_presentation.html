Motivation & Key Challenges
  • Mamba-based models show promise for point cloud learning
  • Two main challenges:
  • - Destroyed 3D point adjacency during SSM processing
  • - Poor long-sequence memory retention for longer inputs
  • Need to preserve spatial dependencies and adapt to varying sequence lengths
StruMamba3D: Paradigm Comparison
  • Transformer: Quadratic complexity, models dependencies via attention
  • Mamba: Linear complexity, but loses spatial adjacency and long-sequence memory
  • StruMamba3D: Maintains spatial dependencies and adapts to sequence length
  • Outperforms Transformer and Mamba-based methods

Structural SSM Block: Key Components
  • Spatial state initialization assigns positions to latent states
  • State-wise update models spatial dependencies between points and states
  • Bidirectional SSM for richer feature propagation
  • Lightweight convolution enhances inter-state interactions
Sequence Length-Adaptive Strategy
  • Adaptive state update mechanism adjusts update frequency by sequence length
  • Spatial state consistency loss enforces robustness to varying input lengths
  • Improves long-sequence memory retention in downstream tasks
Pre-training Framework
  • Masked Point Modeling (MPM) as main pre-training task
  • Spatial state consistency loss aligns student and teacher state features
  • Teacher updated via exponential moving average
